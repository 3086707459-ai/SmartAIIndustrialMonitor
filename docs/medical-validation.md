# BIDMC 真实数据验证（2026-10-26）

## 来源与复现

使用 [PhysioNet BIDMC 1.0.0](https://physionet.org/content/bidmc/1.0.0/)，数据来源、引用和许可见 [datasets/README.md](../datasets/README.md)。下载全部 53 段的 Signals、Numerics、Breaths 三类 CSV，共 159 个原始文件，约 153.33 MB。主站版本目录与官方 archive 镜像的文件均须匹配随源码保存的发布方 SHA-256 清单。

```powershell
python scripts/fetch_bidmc.py --all --mirror
cmake --build --preset demo --target bidmc_benchmark
./build/demo/bin/bidmc_benchmark.exe --data datasets/bidmc --require-records 53 --output build/bidmc-full.json
```

逐文件哈希、原始 URL、大小见下载目录的 `download-manifest.json`。C++ 导入器还使用编译进程序的发布方清单独立核对，GUI 也不能接受被修改后冒充 BIDMC 的 CSV。原始 CSV 以 `-text` Git 属性保留字节，避免 Windows 换行转换破坏哈希。

本次完整证据：[逐窗口评测 JSON](acceptance/bidmc-20261026.json)、[构建与输入溯源](acceptance/medical-20261026-run-info.json)、[回归 JUnit](acceptance/regression-20261026.xml)。

## 真实数据中的边界

| 观察到的问题 | 处理 |
| --- | --- |
| 01 的 PULSE / SpO2 在 111–123 秒为 NaN | 保留 NaN；UI 显示 `—`，不补零、不前向填补 |
| CSV 时间只保留约五位有效数字，如 100.008 秒写成 100.01 | 校验舍入误差，再以样本序号 / 125 Hz 重建精确时标；不从舍入后的差分推测采样率 |
| 人工 CSV 使用从 1 起算的样本序号 | 转成 `(sample-1)/125` 秒；01 首标注 189/187 对应 1.504/1.488 秒，与 WFDB 对应样本 188/186 核对 |
| 06、20 各有一个重复人工标注 | 排序、去重用于展示，重复标注所在的两个 30 秒窗口排除出误差计算；报告保留重复数和排除原因 |
| 09、19 各存在一处人工标注乱序 | 按样本时间排序，保留全部非重复事件；记录原顺序逆序数量 |
| 23 的数值从 -1 秒起，终止于 479 秒 | 原样保留时间偏移；不强制平移到 0 秒，480 秒不显示过期数值 |

以上处理修复数据读取与参考有效性，没有根据逐记录误差调整算法参数。缺失／损坏输入测试可人工制造，以验证错误路径；所有算法效果指标均来自原始公开数据。

## 固定基线及统计口径

1. 从阻抗 RESP 通道取 30 秒、互不重叠的窗口，每段 16 个，共 848 个。末尾 480 秒的端点不构成新窗口。
2. 每 5 个样本求块均值，降至 25 Hz，减去窗口均值。不会读取人工标注来决定估计值。
3. 对 25–250 点滞后计算归一化自相关，对应 6–60 次/分。选择达到最高局部峰值 90% 的最早局部峰；最低周期性为 0.5。算法在完整评测前固定，无训练、拟合或逐记录调参。
4. 含缺失 RESP、平坦波形或周期性不足时不估计。重复人工标注窗口的估计可保留，但不计算误差。
5. 参考为两位标注者各自在 `[start,end)` 窗口内的呼吸数乘以 2，再取两者平均。该计数口径有窗口边界和量化影响；不是瞬时呼吸率的绝对真值。
6. Micro MAE/RMSE/bias 按可评测窗口汇总；Macro MAE 为有可评测窗口的记录 MAE 等权平均。覆盖率分母包含全部 848 个窗口，拒绝窗口不被悄悄删除。

## 实测结果

| 项目 | 结果 |
| --- | --- |
| 原始记录 | 53，159 个文件哈希匹配 |
| 波形点 / 监护仪数值行 | 3,180,053 / 25,493 |
| 总窗口 / 可评测窗口 | 848 / 728 |
| 覆盖率 | 85.85% |
| Micro MAE | 1.2325 次/分 |
| Micro RMSE | 2.5628 次/分 |
| Micro bias | -0.6129 次/分 |
| Macro MAE | 1.3274 次/分 |
| 排除原因 | 周期性不足 118；人工重复标注 2 |

失败表现同样保留：05 只有 2/16 个可评测窗口；23 的 MAE 约 7.45 次/分；13 的 MAE 约 5.72 次/分。平均数不能掩盖这些难例。

当前没有训练集／测试集划分，因为没有训练模型；这组结果只说明固定算法在该数据集上的回顾性表现，不能外推其他人群、设备或真实临床环境。若后续训练或据此调参，需按受试记录隔离开发集和最终测试集，并重新报告拒绝窗口与泛化结果。

## 能力边界

当前直接处理阻抗 RESP，未实现 PPG 呼吸率估计、心律失常分类或疾病诊断。PPG 与 ECG 用于原始信号回放；HR、PULSE、RESP、SpO2 使用发布方监护仪数值，不算作自研模型准确率。缺少真实医疗设备接入、实时监护时限、临床风险评估和临床验证。

下一步应优先分析低覆盖和高误差记录，增加信号质量量化、独立数据集外部测试，再考虑模型训练。任何算法改进都需保留本版完整基线结果以便比较。

## 1.2 窗口审阅与复测（2026-10-28）

本轮升级工作流及评测结果的表达，保持估计算法及参数不变。全 53 段的 848 个窗口逐项核对，误差与 1.1 完全一致：730 个窗口产生估计，846 个窗口参考有效，两者交集 728 个可计分；总体 MAE 1.2325 次/分、覆盖率 85.85%。这三个分母分别保存，不将参考无效当作算法没有输出。

- 新的 Window review 页显示估计、双人参考、带符号误差、周期性和排除原因；支持数值排序、Scored / Excluded 筛选。
- 双击后暂停回放，显示完整 `[start,end)` 30 秒区间，恰好 3,750 个原始样本；避免只看末尾 10 秒或多带入下一个窗口的端点。
- 文件读取、哈希验证和完整评测在同一个后台任务中完成，再一次性发布文档；重载时立即清除旧游标、表格和导出内容。
- 缺少整条人工参考流时，不再将零呼吸数当作可计分参考；缺失的参考、误差及未计算的周期性输出 JSON null / CSV 空字段。信号拒绝和参考排除分别记录，即使同时发生也不互相覆盖。
- JSON schema 2 保留原有指标字段，并增加 `estimated_windows`、`reference_valid_windows`、独立原因计数和每行 `scoring_status`。`accepted_windows` 仍表示估计与有效参考的交集。
- CLI 新增 `--csv`；JSON 与 CSV 均原子写入单个文件，任一写入失败返回非零。两种输出不是跨文件事务；JSON 已成功、CSV 失败时会保留 JSON 并明确报错。
- 离线包增加真实第 05 段，可直接复现 2/16 可计分窗口和 14 个周期性不足窗口。
